# NIH Pre-2026 Six-Element DMSP Format

**Use this only for applications with due dates before May 25, 2026.**
For May 25, 2026 and later, use the 2026 Pilot Format (see `dmsp-2026-format.md`).

The old format is a narrative document, ≤2 pages, addressing six elements.

---

## Element 1: Data Type

Describe the scientific data to be managed and shared, including:
- Types and amount of data generated
- File formats
- Whether the data are raw, processed, or both

## Element 2: Related Tools, Software, and/or Code

Describe any tools or software needed to access or use the shared data.
If custom code is generated, indicate how it will be shared (e.g., GitHub).

## Element 3: Standards

Describe the standards applied to the data and associated metadata
(community standards, ontologies, controlled vocabularies).

## Element 4: Data Preservation, Access, and Associated Timelines

- Where data will be archived for long-term preservation
- How data will be findable and accessible (including access controls for
  human participant data)
- When data will be made available (no later than publication or end of
  performance period, whichever is first)

## Element 5: Access, Distribution, or Reuse Considerations

- Factors affecting access (consent limitations, privacy, IP, confidentiality)
- Whether access will be open or controlled, and why
- Any licenses on the data

## Element 6: Oversight of Data Management and Sharing

- Who will be responsible for data management and sharing
- How compliance will be monitored
- Process for updating the DMSP if plans change

---

For full worked examples in the old format, refer to the OSF Working Group
on DMSP Guidance: https://osf.io/uadxr/
