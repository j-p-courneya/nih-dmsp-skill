4. If you answered "no" to elements 1, 2, or 3, or if you anticipate that
   sharing will be limited in some other way, please describe these
   limitations and the ethical, legal, or technical factors for them.

   This project generates genomic and transcriptomic data from human
   participants. Individual-level sequencing reads, variant calls, and linked
   phenotype data will be shared under controlled access, consistent with
   participant informed consent and the IRB-approved protocol, because they
   carry re-identification risk. Access requires a Data Access Request
   reviewed by an NIH Data Access Committee. Data will be de-identified to
   HIPAA Safe Harbor standards before deposition. De-identified processed
   expression matrices and analysis code will be shared openly.
